# Robot overview source

```sh
python3 make_overview.py ..    # writes ../01-system.svg … ../12-liveview.svg and ../index.html
```

The numbers in the diagrams (timings, limits, leg lengths, gait tables) are copied from the code;
each diagram's function names the file they come from. When that code changes, update the
numbers here and rebuild. No packages are needed beyond Python 3.
